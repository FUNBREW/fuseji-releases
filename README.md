# Fuseji releases

[Fuseji（伏字）](https://funbrew.ltd/products/fuseji) — 日本語 PDF の個人情報を自動で見つけ、復元できない形で墨消しし、検証レポートを出す Mac アプリ — の配布物。
Apple シリコン（M1 以降）・macOS 13 以降。ソースコードは別リポジトリ（private）。

- 最新版: https://github.com/FUNBREW/fuseji-releases/releases/latest
- 最新版の DMG（固定の URL）: https://github.com/FUNBREW/fuseji-releases/releases/latest/download/Fuseji-arm64.dmg
- インストールは DMG を開いて `Applications` へドラッグ。Apple の公証済みです
- 無料版は期限なしで使えます（書き出しに透かし）。有料版のライセンスは製品ページから購入できます
